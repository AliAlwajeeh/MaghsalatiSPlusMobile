# 📱 MaghsalatiSPlusMobile

تطبيق موبايل ذكي لإدارة وتشغيل مغاسل الملابس، مبرمج باستخدام **Flutter** ومربوط مباشرةً مع النظام الخلفي **MaghsalatiSPlus** المبني بـ ASP.NET MVC.

## 🚀 نظرة عامة

يوفر التطبيق واجهة سهلة الاستخدام لعملاء المغسلة وموظفيها، حيث يمكن من خلاله:

- استعراض الطلبات الحالية والسابقة.
- إنشاء طلب غسيل جديد.
- تتبع حالة الطلب (قيد التنفيذ، جاهز، تم التوصيل...).
- استقبال إشعارات فورية حول حالة الطلب.
- تسجيل الدخول باستخدام بيانات العميل أو الموظف.
- التكامل الكامل مع النظام الخلفي **MaghsalatiSPlus** لإدارة الفواتير، العملاء، الطلبات، والتقارير.

## 🧩 التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| الواجهة الأمامية (الموبايل) | Flutter + Dart |
| الواجهة الخلفية | ASP.NET MVC (مشروع MaghsalatiSPlus) |
| API | RESTful APIs |
| إدارة الحالة | Provider |
| التوثيق | JWT Authentication |
| التخزين المحلي | Shared Preferences |

## 🔗 التكامل مع MaghsalatiSPlus

يتم الربط بين التطبيق والنظام الخلفي عبر واجهات برمجية (APIs) تم تطويرها ضمن مشروع **MaghsalatiSPlus**، مما يضمن:

- مزامنة فورية للبيانات.
- أمان عالي في نقل المعلومات.
- تجربة سلسة للمستخدم النهائي.
